# Security Policy

**Website:** https://felixfeger.com  
**Security Contact:** hello@felixfeger.com

## Supported Versions

This project follows a continuous deployment model.

The latest supported version is the code currently available on the `main` branch of this repository.

| Version | Supported |
|---|---|
| Latest `main` build | Yes |
| Previous builds | No guarantee of support |

Any deployment built from the latest `main` branch is considered the latest supported build.

## Reporting a Vulnerability

If you discover a potential security vulnerability affecting this website or its associated services, please report it privately.

**Email:** [hello@felixfeger.com](mailto:hello@felixfeger.com)

Please include the following information where possible:

- A description of the vulnerability.
- The affected page, feature, or service.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant screenshots or supporting information.

Please do not publicly disclose an unpatched vulnerability before allowing reasonable time for investigation and remediation.

## Good Faith Security Research Policy

We support good-faith security research and appreciate individuals who help improve the security of our services.

We consider security research to be conducted in good faith when researchers:

- Make reasonable efforts to avoid privacy violations and service disruptions.
- Do not intentionally access, modify, or delete other people's data.
- Do not exploit vulnerabilities beyond what is reasonably necessary to demonstrate their existence.
- Do not conduct denial-of-service attacks or other disruptive testing.
- Report discovered vulnerabilities promptly and privately.
- Respect applicable laws and the privacy of other users.

For security research conducted in accordance with this policy, we will not pursue legal action or make legal complaints against researchers solely for activities that constitute good-faith security research.

We reserve the right to take appropriate action in cases involving malicious activity, intentional harm, data theft, or activities outside the scope of this policy.

## Response and Remediation

All vulnerability reports will be reviewed as reasonably practicable.

We will make reasonable efforts to:

- Acknowledge vulnerability reports.
- Investigate reported vulnerabilities.
- Determine their severity and potential impact.
- Develop and deploy appropriate fixes.
- Communicate with researchers when additional information is needed.

Response and remediation timelines may vary depending on the complexity and severity of the reported issue.

## Scope

This policy applies to:

- The [felixfeger.com](https://felixfeger.com) website.
- Official website functionality and services operated directly as part of the website.
- Related infrastructure where explicitly authorized for testing.

Third-party services, hosting providers, and external integrations are not automatically included in this policy.

## Policy Updates

This policy applies continuously to the latest supported build.

The latest version of the website is defined by the current `main` branch of this repository.

This policy does not require a separate version number or manual update for every software deployment.

We reserve the right to revise this policy when necessary.
